# AI 辅助学习闭环公开实验

这是一个非商业、低成本的公开实验：验证学过 AI、编程或其他技术长课以后，用一个固定的短闭环，能否比继续看课或整理笔记更容易做出实际成果。

它不提供课程内容，不要求上传课程资料，也不承诺学习或就业结果。

## 要验证的问题

很多人并不是完全没有学习，而是出现这些情况：

- 跟着课程能做，离开课程不知道下一步；
- 记了很多笔记，遇到真实任务仍不会用；
- 买过或学过长课，但一直没有形成自己的小项目；
- 使用 AI 时得到很多答案，却没有形成可复用的能力。

本实验只验证一件事：把一次学习限制在 20～40 分钟，并强制产生一个最小成果，是否能提高开始率、持续率和产出率。

## 一次 20～40 分钟的闭环

1. **定一个小目标（3 分钟）**：写明今天要完成的可检查结果。
2. **先回忆（5 分钟）**：不看资料，写下已知步骤、未知点和可能卡点。
3. **让 AI 查漏（5～10 分钟）**：只让 AI 指出缺口、错误和下一步，不让它包办全部任务。
4. **动手产出（10～20 分钟）**：完成代码、运行结果、流程图、说明文字或测试记录中的一种。
5. **简短复盘（3 分钟）**：记录完成程度、真实卡点和下一轮动作。

## 最小记录模板

```text
本轮目标：
我的初始回忆：
AI 指出的一个关键缺口：
本轮最小产出：
完成 / 部分完成 / 卡住：
下一轮唯一动作：
```

## 7 天公开试用

正在寻找 3～5 位有类似经历的人，自愿完成两轮练习。课程和小任务由参与者自己选择，每轮约 20～40 分钟，可以随时退出。

如果愿意参加，请到 [Discussion #1](https://github.com/chuangyuchen94/ai-learning-loop-experiment/discussions/1) 回复：

- 学习方向；
- 目前最常卡在哪里；
- 未来 7 天能否投入两次。

## 安全与版权边界

- 不提交公司、客户或其他人的资料；
- 不提交账号、密码、密钥、真实姓名或联系方式；
- 不复制、上传或传播付费课程原文；
- 只使用参与者自己的描述、笔记和非敏感小任务；
- 公开总结只记录匿名完成情况和共性反馈。

## 判断标准

实验不以点赞或口头兴趣为成功：至少 3 人实际开始、至少 2 人完成两轮，并且至少 2 人主动要求继续或提出具体改进，才进入下一轮。
